# LoopATempo Privacy

LoopATempo stores your habits, check-ins, and settings on your device.

## Network access
The app has one network feature. When you open **Profile → About**, it reads the public release notes for this app from GitHub (`api.github.com`). It sends nothing about you or your data. GitHub receives the usual connection details, such as your IP address, as with any website visit.

## What the app reads
- **App usage time** through Android's Usage access permission. It is used only to count daily app streaks. Usage times are not saved. Only the daily streak result is stored.

## Background tracking
If "Keep tracking alive" is on, LoopATempo runs a background service so it can check app usage while you use other apps. Android shows a silent notification while this runs. When the phone restarts, the app restarts this service if the setting is on. You can turn it off in Settings → Tasks.

## Export and import
Export saves a backup file wherever you choose, such as Downloads or cloud storage you use yourself. Import replaces everything in the app with the contents of a backup file you pick. The file is not encrypted, so anyone with it can read your habit names and check-in history. Store it carefully.

## Other data
The app has no accounts, analytics, advertising, or crash reporting, and it does not send your data anywhere.

## Removing your data
- Delete habits in the Edit tab, or uninstall the app to remove all local data.
- Delete any exported backup files you no longer need.
